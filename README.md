# JGMS-100hires
### Portfolio project for job application


**TOOLS INSTALLED**
+ Cursor IDE
+ Claude Code for VS Code
+ Codex – OpenAI’s coding agent
+ GitHub Actions

**COMPLETED STEPS**
1. Downloaded and installed Cursor IDE from https://cursor.com/

2. Installed the Claude Code extension in Cursor and ~log in~.
> Upon opening Claude Code in Cursor, all the login options it presented required a premium account or at least a card for billing to proceed. I left this step as is as I don't have a premium account for Claude. Also, based on my research, if ran through the official extension for Cursor, it is not possible to bypass the billing required. Although I have succeeded in using Claude when ran through the terminal (not the official extension) by using a free Gemini API key from https://aistudio.google.com/ (following instructions from https://prince-arora-aws.medium.com/how-i-set-up-claude-code-for-free-no-subscription-no-credit-card-and-what-i-learned-along-the-2cba880682a2).

3. Installed the Codex extension in Cursor and logged in with my free OpenAI account.

4. Created a new github account for my portfolio at https://github.com/ and a public repository for this project.

5. Used Git: Clone in Cursor to open the repository. 

6. Wrote a README.md file that describes the tools installed, steps completed, and issues and its resolutions that arose in the process.

7. Set global Git identity (name & email) through git config in the terminal.

8. Commited and pushed to GitHub.
